# Die Wichtel-Maschine App-Test

Diese Version enthält die App-Ansicht mit sichtbarem Einstellungsmenü.

## GitHub Pages

1. Den Inhalt dieses Ordners in ein GitHub-Repository hochladen.
2. Unter **Settings > Pages** als Quelle **Deploy from a branch** auswählen.
3. Branch `main` und Ordner `/(root)` einstellen.
4. Die bereitgestellte GitHub-Pages-Adresse in Chrome auf dem Handy öffnen.
5. Im Chrome-Menü **App installieren** auswählen.

Die App funktioniert nach dem ersten Laden auch offline.
